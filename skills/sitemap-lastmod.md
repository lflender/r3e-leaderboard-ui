# Skill: Sitemap Lastmod

- Update `sitemap.xml` `lastmod` when changing user-facing pages or page-related modules.
- Affected files include `index.html`, `drivers.html`, `leaderboards.html`, `cars.html`, `records.html`, `faq.html`, page modules under `modules/pages/*.js`, and shared modules that affect page content.
- Use `YYYY-MM-DD`.
- Do not add `detail.html` to the sitemap.
